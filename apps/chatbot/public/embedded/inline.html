Inline / aside

Here the widget is docked into the page layout as a sidebar. There is no bubble and no close button — the page already allocated space, so hiding the content behind a click would only add friction.

The chat UI is the exact same component floating mode renders. Only the container around it differs, which is what the trigger / container / content split buys.
